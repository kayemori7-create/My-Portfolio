Web Design Work Sample

Real client site builds across three different platforms — showing the same eye for clean, conversion-focused layout regardless of the tool behind it.

Webflow WordPress Elementor BoldGrid

Context: Three client builds, three different stacks: a wellness clinic site built in Webflow, a dental clinic site built in WordPress with Elementor, and a dental hygiene clinic site built in WordPress with BoldGrid. Each one required working within that platform's own constraints to get a clean, on-brand result.

Note: I'm no longer working with the EG Dental Clinic or Disc Therapy Institute accounts, and I wasn't able to screenshot every page I built at the time. The live sites linked below may have changed since this work was done and may no longer reflect it.

Webflow — Disc Therapy Institute

A South Florida pain-relief and wellness clinic site, built visually in Webflow with a clear treatment-first layout. No longer a client — current site: disctherapy.marksonchiropractic.com, now a subdomain of Markson Chiropractic.

WordPress + Elementor — EG Dental Clinic

A bilingual dental clinic site in Tijuana, Mexico, built in WordPress using the Elementor page builder. No longer a client — current site: egdentalmex.com.

WordPress + BoldGrid — Holistic Dental Hygiene Clinic

A Calgary hygienist practice site, built in WordPress on the BoldGrid theme — worked around BoldGrid's layout limits to keep the design clean. Current, active client — live site: holisticdentalhygiene.ca.
